5. CALCULATE
Human handling cost = sum over roles of (minutes / 60 * loaded hourly cost)
Operating cost = all model/tool attempts + human handling + operation/support
Cost including allocated setup = operating cost + implementation allocation
Cost per accepted result = cost including allocated setup / accepted results
Also show operating cost per accepted result without setup allocation.
If there are no accepted results, report no completed output; do not divide
by zero or report a zero cost per accepted result.

Keep failed attempts in costs. Do not count unresolved work as accepted.
Match expenses to outcomes. In a pilot, follow a batch through completion
rather than dividing one month's unfinished work by another month's output.
When later checks reveal errors, revise acceptance and add recovery costs.

THE GUIDE'S FICTIONAL EXAMPLE
N = monthly enquiries, all assumed accepted eventually.
Loaded handling cost = $30/hour. Setup allocated over 12 months.
Manual monthly cost = 3.00 * N
Reviewed AI drafts monthly cost = 500 + 1.65 * N
Bounded automation monthly cost = 1600 + 0.72 * N

At N=1000: $3000 / $2150 / $2320, or $3.00 / $2.15 / $2.32 per result.
Drafts: 2 review minutes on all tasks + 6 extra minutes on 20%;
$0.05 usage per input; $250 monthly support; $3000 upfront setup.
Bounded: 20% reviewed for 2 minutes, 10% directly handled for 6 minutes,
70% automatic-path tasks, 10% of those audited for 2 minutes;
$0.15 usage per input; $600 monthly support; $12000 upfront setup.
Usage includes retries; support excludes handling already counted above.
All rates and prices are illustrative, not client data or market averages.
